# Storylines

Three films were written before anything was built. **A was built.** B and C are kept so a later pass can switch.

The one thing: *MicroEngine is a small kernel with sockets; what a game needs is a module seated in one, and there is
always room for another.* Every line on screen is the project's own copy (the site, the design notes, a sample).

## A. Seated (built)

- **Device and form:** the object is the explanation, told as an object-to-object chain. The brand's own device, a
  socket and its module, carries the film.
- **What the viewer sees:** code becomes a sprite, the sprite's pixel becomes real games, a game pulls back onto the
  board that runs it, modules seat and one is swapped while the game plays on, and the board closes into the mark.
- **First two seconds:** warm paper, a graphite code panel, a real string map arriving line by line under "Code first."
- **Beats:** hook (code) → reveal (the sprite it draws) → payoff 1 (real games) → proof (kernel, sockets, a swap) →
  claim ("A game engine that orchestrates, not reinvents.") → end card (the module seats in the mark).
- **Look:** the site's "Socket" system: warm paper and graphite, amber only for the module, Bricolage Grotesque and
  IBM Plex, pixel art only inside the games' own frames.
- **Sound:** a 120 BPM chip score written as a MicroEngine `Song`, effects from its `Synth`; near silence for the
  code, full drums when the games arrive, one heavy hit when the module seats in the mark.

## B. Fixed step

- **Device and form:** one frame that rebuilds, on a visible clock. A film strip advances exactly one tick per beat;
  every tick shows the same instant of a game as input, simulation and picture.
- **Why not:** austere and technical; it explains the loop, not what the engine stands for.
- **Look and sound:** graphite strip, mono labels, a metronome that becomes the drum track.

## C. Parts list

- **Device and form:** type carries the argument, cut on the beat. The engine as a parts list read aloud by giant
  kinetic type, each word seated like a module, ending on the empty line of the list.
- **Why not:** a list of parts dates the moment a part changes, and it shows no game.
- **Look and sound:** paper, one ink, amber underline; percussion only.
