# Storylines, third film

Two films exist. "Seated" tells the result: code becomes a game. "Assembly" tells the architecture: a
kernel, pieces that connect to it, configurations. Both are about space: what is on the screen, what is on the board.

What neither says is what the kernel does once everything is seated. The documentation says it in one sentence,
three times: **"The loop owns time."** The engine's first decision is a clock: time cut into fixed steps, each run in
the same order, so the same steps give the same game. That is a philosophy of development, not a feature, and it is
MicroEngine's own.

The one thing: *the engine keeps the beat and the order; what happens in each step is yours.*

## A. Every step (built)

- **Device and form:** one frame that rebuilds, in one take. A tape of steps runs under a playhead; the tape is the
  film's own score, so every cell that lights is a note being heard.
- **What the viewer sees:** a single beating block; it becomes a playhead over a tape of equal steps; one step opens
  to show its order; the tape runs twice and matches; a dark world opens from the playhead and the tape runs into
  depth, full of things happening; it all folds back to the one block, and the mark closes over it.
- **First two seconds:** warm paper, "A game is made of time", an amber block that beats twice.
- **Look:** ink and amber on paper, inverted for the middle. No colour that is not in the mark.
- **Sound:** 100 BPM, slower than the other two; the kick alone, then voices one by one; silence of drums inside
  the opened step; the full band only where the copy says "yours".

## B. The game decides

- **Device and form:** type carries the argument, cut on the beat. The design principles as pairs: "The engine keeps
  score, the game decides", "Actions, never keys", "Plain entities", each pair a full-frame composition.
- **Why not:** a list of principles is a manifesto slide deck, and several of them name today's features.

## C. No editor

- **Device and form:** a moment in someone's day. A text editor, a test run, a game: the developer's whole loop with
  nothing else on screen.
- **Why not:** it needs code and a game on screen, which is "Seated" again, and "no visual editor" is a state of
  the roadmap, not an identity to fix in a film.
