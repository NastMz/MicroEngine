## Subjective-only handoff after technical delivery

Run from any directory:

~~~powershell
dotnet run --project C:\Proyectos\MicroEngine\examples\RoomExplorer\RoomExplorer.csproj -c Release
~~~

Arrows or WASD move in four directions; Escape/window close exits. Start in the green Courtyard. Move right through the cyan edge passage, aligned with its opening, to the purple Hall; return via its left passage. Room changes print room:Hall or room:Courtyard. These are source-authored navigable areas, not a map format or renderer feature. The gold24x32body stays inside logical bounds; there are no internal solid objects.

Evaluate only navigation response, passage discoverability, room differentiation and transition feel. Automated proofs of movement/bounds/CLI/errors/native cleanup are agent-owned, not homework. No subjective success claimed until feedback arrives, and no full-H2 acceptance inferred from positive tracer feedback.
