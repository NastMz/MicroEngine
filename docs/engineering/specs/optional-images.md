# IMG-1 — Optional in-memory image resources

Status: approved2026-10-17 by Codex root after checkpoint_design_review PASS under ADR-0009; CAP-004/006, FR-001/002, NFR-001/002/004/005. One tiny avatar supplement and image ownership, not file decoding/assets/full sprites.

## Public data/profile

MicroEngine.Loop public sealed PixelImage(int width,int height,ReadOnlySpan<Rgba> pixels): positive dimensions else ArgumentOutOfRangeException, (long)width*height must equal pixels.Length else ArgumentException before copy. Width/Height and IReadOnlyList<Rgba> Pixels get-only; copy input, expose immutable wrapper, row-major top-left, straight RGBA. CPU value owns no native resource/IDisposable and may be reused across providers. Standard constructor argument errors are data configuration errors, not frame-origin misuse. No universal GPU dimension promise.

IImageResource : IDisposable exposes get-only int Width/Height metadata, valid after disposal. IImageCanvas : ICanvas exposes IImageResource CreateImage(PixelImage image), void DrawImage(IImageResource image,Rect destination). Optional discovery; base ICanvas/ILabelCanvas/IFramePlatform unchanged. Whole-image nearest/point sampling, top-left destination coordinates and normal source-over alpha; no crop/tint/rotation/flip/filter/atlas API. Valid destination finite X/Y/Width/Height with nonnegative sizes, zero extent validated no-op. Null image/value, foreign/released lease and invalid rectangle are FrameApiException via public FrameApi.Require; owner/lifetime guards precede data checks, all validation before native effects. Valid unsupported hardware/budget requests and native failures are ordinary exceptions/execution failures, never mislabeled misuse.

Create/draw require committed drawing and current provider context thread; leases are context-bound. Dispose always checks owner thread, then idempotent no-op if already invalidated; live disposal during drawing throws FrameApiException without release/invalidation. Outside drawing: invalidate once/remove tracking BEFORE one native release attempt; failure propagated, no retry/use of uncertain handle. Metadata read-only/available without native call. Window cleanup ends active drawing first, then attempts all remaining image releases reverse-acquisition order, then Close. Retain errors in End/reverse-images/Close order; single error rethrown with origin, multiple AggregateException. Close failure retains poisoned reservation, Close success releases reservation even if child cleanup failed; all leases invalidated. No promise of successful native release after a reported failure.

Desktop IDesktopApi adds private object CreateImage(PixelImage), DrawImage(object,Rect), ReleaseImage(object) seam; no object/native type in public profile. Native factory cleans temporary CPU image and any failed/partially committed texture before propagating errors. Platform registers lease only after successful creation; null native result is InvalidOperationException, registration failure attempts native cleanup with both causes retained. Desktop max256per dimension/32live leases -> NotSupportedException before native effects, releasing restores budget. Raylib maps RGBA to CPU image, upload/validate texture, free temporary CPU data, explicit point sampling and white-tinted whole-image draw; lease release unloads texture. Existing drawing/window/input/label traces unchanged when images unused.

## Consumer

New internal AvatarImage : IDisposable in FirstPlayable, per-run (never static native handle). Static immutable2x2 source: turquoise(70,200,210), white(255,255,255), transparent(0,0,0,0), dark(24,28,40). Draw(ICanvas,float x,float y) checks canvas/non-disposed/finite coordinates, if no IImageCanvas does nothing; otherwise lazily creates one lease and draws at(x+8,y+14,8,8). Same provider for run, no hot swapping. Dispose forwards once and marks helper disposed; after window cleanup lease Dispose is safe no-op. Program owns helper in using, invokes after existing AvatarRenderer.Draw; existing movement/pose/facing/Fill geometry untouched. Badge supplements torso only; no art/animation pipeline or public genre abstraction. Fallback retains exact old rectangle rendering.
