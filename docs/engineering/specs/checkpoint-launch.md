## CLI and error contract

TurnExplorer retains --smoke N(1..600), --fail-update, controls/render/loop/outcome/cleanup traces and exits0success/1executionfailure/2usage. Add optional --load PATH and --save-new PATH each at most once, any order with old flags. PATH must nonblank and must not start with `--` (avoid consuming next flag); relative paths accepted, resolved by CF-1. Reject missing/blank/duplicate/unknown flags before ANY IO/native acquisition, Usage on stderr and2. Internal immutable LaunchOptions.TryParse(string[] args,out LaunchOptions? options), nullargs ArgumentNullException, failureoptionsnull, fields Limit/FailUpdate/LoadPath/SaveNewPath. No CLI option names/positional arity changes to old flags, no help flag introduced.

Usage: TurnExplorer [--smoke N(1..600)] [--fail-update] [--load PATH] [--save-new PATH]

After successful parsing, load via CheckpointFile.Read then TurnSession.Restore BEFORE creating DesktopPlatform/controls/loop. Successful load prints `checkpoint:loaded`; read/format/restore failure prints `checkpoint:load-failed:<ExceptionType>:<message>` to stderr and returns1, no window/default fallback/output file. No-load starts parameterless session exactly as before. Startup exceptions for requested persistence are caught/reported, not engine failures or usage2.

Run same game and report original outcome/primary/cleanup traces. If report.Outcome==Failed return1 WITHOUT saving or success checkpoint trace. Otherwise, if --save-new supplied, call CheckpointFile.CreateNew only AFTER FrameLoop returns (native cleanup already attempted/completed per report). On success print `checkpoint:saved`, return0; on save failure print `checkpoint:save-failed:<ExceptionType>:<message>` stderr/return1 while truthful loop outcome remains as reported. Without --save-new no disk writes. No IO in update/render; no hot reload/keybinding/save slots/overwrite/autosave/default folder/recovery. Load and save same existing path is allowed but save fails non-destructively with1 after clean close. Paths/messages caller-selected; no hidden statefiles.
