## Public reusable contracts
New engine/TwoD project references Loop, no packages/native types. StaticWorld(IEnumerable<Rect>) validates finite positive sizes/endpoints, copies nonoverlapping-or-touching boxes; Move(Rect body,float dx,float dy) validates finite positive body/no initial strict solid overlap and finite displacement/result, then X sweep followed by Y sweep. Result Motion(Rect Bounds,bool BlockedX,bool BlockedY); no tunneling along one axis, strict perpendicular overlap, nearest surface independent of enumeration. Starting edge/contact can move away; zero displacement does not report blockage. Overlaps(Rect,Rect) strict intersection validated. No gravity/support/body storage/scene rules.
FrameAnimation(IEnumerable<Rect> frames,TimeSpan frameDuration): nonempty copied valid positive finite integer regions, duration>0; Current get-only Rect; Advance(TimeSpan elapsed) accepts>=0 and handles MaxValue without tick overflow via modular arithmetic; Reset returns first frame. This horizon loops, no event/crossfade/state graph. Consumer chooses idle/jump versus walk.
ImageSet(IReadOnlyDictionary<string,PixelImage>) copies nonempty valid keys/non-null data, lazily acquires each key once from one IImageCanvas on Get(canvas,key); validates disposed/key/provider identity before effects. Unknown keys throw KeyNotFoundException; provider mismatch InvalidOperationException; closing/disposed Get throws ObjectDisposedException, all before native effects. Bind provider only after first successful non-null acquisition; failed first acquisition leaves unbound. On failed later acquisition prior leases remain owned/reusable; no null leases accepted. Dispose sets closing state before reverse-order attempts all; successful releases removed, failed leases retained for a later Dispose retry (including wrong-time drawing rejection). Only zero remaining leases marks fully disposed; aggregate failures reported, no new Get after closing. Normally called outside drawing after FrameLoop/window cleanup. No per-game GPU cache/decoding in consumer.
DesktopImageDecoder.Decode(byte[] encodedPng): null/empty/type/PNG-header/truncation/dimension budget (<=8192peraxis and<=16777216pixels) validate before native decode; decoded dimensions must match header, RGBA copied into immutable PixelImage; CPU native image always freed, native failure ordinary InvalidDataException. Decoder runs on caller thread before GPU lifetime; no graphics context required. PNG only this adapter, not universal image contract. DesktopWindowOptions existing constructor retained; new(width,height,title,maxImageDimension,maxImageResources) with1..8192/1..256; existing256/32 defaults retained. GPU allocation/native support may still fail normally.
