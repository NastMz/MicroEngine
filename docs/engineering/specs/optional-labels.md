# NL-1 — Optional short ASCII labels

Status: approved2026-10-17 by Codex root after checkpoint_design_review PASS, ADR-0008; CAP-004/012, FR-001/002, NFR-001/002/004/005. Scope real menu labels, not a UI toolkit/asset/font manager.

## Public profile and provider contract

Add public interface ILabelCanvas : ICanvas { void Label(string text, int x, int y, int pixelSize, Rgba color); } in MicroEngine.Loop. ICanvas/IFramePlatform unchanged, no dependency/package change. Optional capability discovery by type-test, never require every provider to implement it. Shared semantics: text nonnull, length0..80, chars U+0020..U+007E only (no tabs/newlines/NUL/non-ASCII); pixelSize10..64 inclusive. Coordinates integers in existing top-left pixel coordinate space, negative/offscreen permitted. Font/provider metrics not standardized. Empty text is validated no-op, not a native call; otherwise draw in call order, current framebuffer, no retained reference/resource transferred. Same committed-drawing/owner-thread/not-disposed lifetime as Canvas. Invalid usage is FrameApiException via public FrameApi.Require, not ordinary execution failure; check lifetime before parameters, validate all before native effects. Providers may support richer text separately, not silently accept unsupported NL-1 data.

Desktop CanvasView advertises ILabelCanvas. Add internal IDesktopApi.Label and RaylibApi forwards to pinned Raylib.DrawText with default face, int coordinates/size and exact Rgba conversion. Window owns native face; no explicit external font acquire/unload or persistent native handles. Existing Clear/Fill/Poll/Begin/End/Dispose semantics unchanged. Native Label exceptions remain ordinary execution failures unless public origin guard identifies misuse; tests pin cleanup and classification. Private test API seam is not public extension route.

No label calls closed/afterReturn; pure rendering, no model state/IO/console trace changes. Nonlabel providers retain glyphs/console names, no exception/cast requirement. This additively supersedes prior console-only presentation, not game rules or old acceptance evidence.
