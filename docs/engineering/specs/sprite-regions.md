# SPR-1 — Optional sprite-region presentation

Status: approved2026-10-17 by Codex root after checkpoint_design_review PASS; ME-041 completed, ME-042 claimed in-progress on baseline7507858. CAP-004/006/008/016, FR-001/002, NFR-001/002/004/005. This extends IMG-1 through a separate optional capability; no mandatory sprite/animation system.

## Provider contract

Add `IImageRegionCanvas : IImageCanvas` with `void DrawImageRegion(IImageResource image, Rect source, Rect destination)`. Existing ICanvas, ILabelCanvas, IImageCanvas and IFramePlatform methods and behavior stay unchanged. Source is a top-left pixel rectangle: all four values finite integers, X/Y nonnegative, Width/Height strictly positive, entirely inside the resource dimensions. Negative sizes do not imply flip. Destination follows IMG-1 finite/nonnegative-size rules; validated zero extent is a no-op. No tint/rotation/flip/filter/atlas metadata. Point sampling and normal source-over alpha as IMG-1.

Desktop checks owner thread/committed drawing first; then live resource identity/owning provider, then source and destination. All validation precedes native effects, including zero destination. Invalid calls throw FrameApiException; valid native draw failure is an ordinary execution failure. Resource creation/release/budget/metadata/window cleanup remain IMG-1 unchanged. Internal seam adds DrawImageRegion(object,Rect,Rect); Raylib DrawTexturePro uses positive supplied source and destination, white tint/zero origin/rotation. No vendor types in public contracts.

## Consumer proof

Keep AvatarRenderer, AvatarImage and AvatarAnimation unchanged. New internal per-run AvatarSprites owns one optional sheet lease and an AvatarImage fallback helper. `Draw(ICanvas,float x,float y,AvatarAnimation animation)` validates nonnull canvas/animation, not disposed, finite position, before capability discovery. If IImageRegionCanvas exists, lazily upload one immutable source-authored192x32 RGBA sheet: eight24x32 cells, ordered right-facing idle/walk0/walk1/air then left-facing idle/walk0/walk1/air. Each cell is rasterized from the existing AvatarRenderer at integer coordinates using private CPU ICanvas; include the exact existing2x2 badge expanded4x per pixel at(8,14), using source-over (transparent pixels preserve the torso). Transparent background. Build immutable CPU source once without native state; animation fixtures use the existing public Update behavior. Source selection = facingOffset + pose frame; destination(x,y,24,32). Read simulation state only: no playback clock/randomness/mutation in presentation.

Without region support, call existing AvatarRenderer then AvatarImage for the exact current whole-image badge or primitive-only fallback. Program replaces its two renderer calls with one AvatarSprites.Draw, owns helper with using. Per-run single provider; no hot-swap promise. Dispose once/invalidate helper before forwarding release; fallback helper and sheet are mutually exclusive in the supported run. After window cleanup lease disposal remains same-thread no-op. Raster helper and sheet layout are consumer-private, not engine atlas/clip APIs. Existing source appearance/animation/timing/game model stay the same; this is a renderer-path migration, not new art.
