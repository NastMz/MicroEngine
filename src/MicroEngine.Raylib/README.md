# MicroEngine.Raylib

The raylib platform of [MicroEngine](https://github.com/NastMz/MicroEngine): the desktop alternative to SDL 3
(`--platform raylib`) on Windows, Linux and macOS. Browser builds run on SDL 3 (`MicroEngine.Sdl`).

MicroEngine is in **Alpha** (0.x): public APIs may change incompatibly between versions; each change is listed in the
[migration notes](https://github.com/NastMz/MicroEngine/blob/main/docs/migrations.md). MIT licensed.
