# Contributing to MicroEngine

Start with the [engineering contribution guide](docs/engineering/contributing.md).
Read the [manifesto](docs/engineering/manifesto.md), [requirements](docs/engineering/requirements.md),
[decisions](docs/engineering/decisions/README.md) and [roadmap](docs/engineering/roadmap.md).

No new engine is implemented; no greenfield build/test command exists yet.
Do not infer technical approval from historical implementations or agent proposals.
Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Significant decisions need explicit
approval and relevant documentation must accompany authorized behavior changes.

The prototype and its contributor guide are available through [history](docs/engineering/history.md).
