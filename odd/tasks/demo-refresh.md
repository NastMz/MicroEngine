# DEMO-REFRESH: technical and artistic modernization of the four demos

Objective: make Meadow Run, Courtyard Key, Trail Duel and Neon Rift idiomatic references of the post-ARCH-1 SDK, and raise the art of Courtyard Key and Trail Duel. Branches `feat/demo-refresh-<game>` (one PR per unit, CI green before merge).
Delivery: `single-pr` per game unit, merged by the parent after review and CI; no release, package or production deploy. Runner: MSTest (`dotnet test MicroEngine.slnx -c Release`), scripted captures (`--script --hidden --mute --captures`).

## Specs

- S1 Technical audit and modernization of all four games: "Moderniza las implementaciones cuando exista una mejora demostrable en claridad, mantenibilidad, corrección, rendimiento o aprovechamiento del SDK." "No busco una reescritura indiscriminada ni una adopción artificial de todas las APIs nuevas. Si una solución actual es apropiada, consérvala."
- S2 Art: "Courtyard Key y Trail Duel son las prioridades artísticas." "pixel art de mayor calidad, riqueza y expresividad, tomando como referencia el salto de calidad visual que históricamente existió entre los videojuegos de Game Boy Advance y Nintendo DS." "Quiero arte original, con identidad propia y una dirección artística coherente para cada título." "No te limites a aumentar la resolución de los sprites existentes." Revised after the prototypes (L4b): external packs are allowed and preferred where code art falls short ("busca un pack para lo que tú veas que definitivamente no puedes montar bien"); one coherent pack family per game; the games stay hybrid. Licence: CC0 or CC-BY only.
- S3 "Meadow Run y Neon Rift tienen una identidad visual que queremos preservar." "Especialmente Neon Rift debe conservar su carácter de run-and-gun retro."
- S4 "Los cuatro juegos deben conservar su identidad, mecánicas fundamentales, contenido y experiencia de juego." "No elimines funcionalidades ni simplifiques contenido para facilitar la modernización." New art must fit "la cámara, las colisiones, las animaciones, los efectos y las dimensiones reales de cada juego."
- S5 Demos as SDK references: "Sus implementaciones deben reflejar prácticas actuales, idiomáticas y sostenibles para el SDK reconstruido." "Revisa también ejemplos y documentación que dependan de implementaciones antiguas."
- S6 Scope: "Esta misión no autoriza otra reconstrucción del kernel ni un rediseño preventivo del SDK." Engine defects only by "el cambio mínimo justificado, con pruebas".
- S7 Owner review reserved for "decisiones que alteren sustancialmente la identidad o jugabilidad de un título, impliquen cambios fundamentales del SDK o requieran publicación." No releases, packages or production deploys.
- S8 Acceptance: games build and pass tests and CI; mechanics, progression and saves kept; visual review of "escenas representativas, transiciones, interfaces y estados relevantes"; no per-frame allocation or resource regressions; docs match the final code; external assets properly licensed.
- S9 Delivery: "un resumen por juego que explique las mejoras técnicas, los cambios artísticos, las decisiones importantes y la evidencia de validación", plus SDK practices demonstrated and real limitations found.

## Log

- L1 2026-11-05 Original request: DEMO-REFRESH mission text (owner, verbatim in the session; key strings quoted in Specs).
- L2 2026-11-05 Audit findings (T1):
  - All four games load content with `new ContentFolder()` / `PathOf` / `AddSoundFile(path)` instead of `Game.Assets` (ADR 0034, migrations item 7).
  - Courtyard Key and Trail Duel advance fades and presentation coroutines by a hard-coded `1/60f` (ADR 0027).
  - Trail Duel hand-writes every menu and dialogue (`TextPanel`, `ChoiceMenu`), duplicating `SelectionList` and `DialogueBox`; Courtyard Key's HUD duplicates toast timers.
  - Meadow Run: the best-coins record is wrong when 100 coins wrap into a life (`Scenes/PlayScene.cs:109`); `ParticleSpec with` allocates per dust emit; `smoke.script` traces depend on the user's save folder.
  - Neon Rift: `Content/Stages.cs` and `Content/StageDef.cs` are source files inside the shipped content folder; high score is faked (`StageView.cs:145`) and not saved; README says "one hit is fatal" while the player has 3 health.
  - Art: Courtyard Key is almost fully procedural (one recoloured CC0 PNG); Trail Duel draws world, UI and stages in code and uses 14 Openmon creature PNGs from several artists, with the player's creature shown as its mirrored front sprite.
  - Docs: 30 unchecked `Source: games/...` excerpts in `docs/manual/*.md`; `docs/architecture.md:297` still recommends the removed `EntityList<T>`.
  - No engine change is required by any finding.
